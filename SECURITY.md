# Security policy

Do not report vulnerabilities in a public issue. Email the maintainers through the security contact configured for the repository, with a concise reproduction, affected version or commit, impact, and any safe mitigation.

Please do not include customer data, credentials, tokens, DSNs, raw production logs, or private documents. We will acknowledge a report, assess scope, and coordinate a fix before public disclosure.

For routine bugs, setup questions, and feature ideas, use the normal issue tracker.
