# v1.0.0 单机稳定版

AgentBridge v1.0.0 是面向 Vibe Coding 的源码型业务 AI 底座单机稳定版。

## 已包含

- 业务插件、工具权限双检、租户隔离、JSON/SSE 流式协议；
- 会话冲突、取消、审批恢复、事件落库、运行记录、回放和 OTel span；
- `work_order_ops` 黄金案例：工单列表、统计图表、知识引用、草稿、人工审批和幂等创建；
- 本地管理员认证、模型配置加密、管理中心、插件/工具/提示词/用量/知识页面；
- Fake、PostgreSQL/pgvector、external 和 RAG-Agent 知识后端边界；
- Python、API、Core、Web、架构和发布文档门禁。

## 发布边界

v1.0.0 的主承诺是单机部署。Fake 模型和 Fake 知识后端用于离线验证；真实模型、pgvector 和外部 RAG 按需配置。

生产部署演练、迁移恢复、具体 IdP 联调和双实例/多机验证属于 1.0 之后的后续工程，不影响单机版本发布，也不代表默认多机承诺。

真实 Docker Compose smoke 依赖使用者本机的 Docker Engine、镜像网络和数据卷环境，部署前请按 `docs/deploy.md` 执行并保留结果。
