# v0.1.0 技术预览

## 可体验

- 流式对话与稳定 SSE 事件；
- domain 业务插件、工具权限列表过滤与调用期复检；
- 审计、事件回放、基础 RAG 接入和调试控制台。

## 推荐环境

Python 3.12+ 与 PostgreSQL。使用 RAG 时另需 pgvector、`apps/api[rag]` extra 和兼容的 embedding 服务；完整配置见[部署说明](../deploy.md)。

## 已知限制

- P1 工单黄金案例实现已合入并完成真实 PG/RAG 验收；
- `rag_agent_pg` 以只读方式接入固定演示租户 `rag-agent-demo`；
- P2-A 运行、安全、RAG 与控制台验证已完成；P2-B 部署、恢复、具体 IdP 与多机验证尚未完成；
- 多机不是默认承诺；
- `external` 后端不支持摄取时，`POST /ingest` 返回 501。

## 升级与反馈

配置变更前先备份。一般问题走 Issue。公开 tag 或 release 前，必须先发布 `SECURITY.md` 中的私密漏洞报告渠道；在此之前，本文仅为仓库内技术预览草案，不得据此创建公开发布。
